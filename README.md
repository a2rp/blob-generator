# Blob Generator

![Blob Generator preview](screenshot.png)

A focused React and Vite tool for creating organic CSS blobs. Adjust dimensions, corner radii, gradient angle, and colors, then copy the generated CSS.

## Features

- Live blob preview with adjustable width and height.
- Independent corner radius controls.
- Gradient angle and color controls.
- Randomize, reset, and copy CSS actions.
- Responsive layout with a fixed branded header, footer links, and Go to top control.

## Tech stack

React 18, Vite, styled-components, React Icons, and CSS.

## Run locally

Requires Node.js 20.19 or newer.

```bash
npm install
npm run dev
```

Build and preview the production version:

```bash
npm run build
npm run preview
```

Deploy to the configured GitHub Pages branch:

```bash
npm run deploy
```

Live URL: [a2rp.github.io/blob-generator](https://a2rp.github.io/blob-generator/)
